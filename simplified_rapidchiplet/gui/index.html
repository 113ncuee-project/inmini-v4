01　PPA 限制

勾選並設定上限。「嚴格遵守」決定最終推薦的必要條件；未勾選則作為軟目標。

Power：同一 batch 推論時間窗的平均 E/T。Area：compute、IO 與 DRAM 的模型矽面積。Latency：指定 batch 完成時間。

02　PPA 偏好

以固定起點參考值正規化 Power／Area／Latency，加權比較。Energy 獨立呈現。

03　模型組合

真實模型預設 224×224 FX DAG，保留 residual／Add 相依。多模型需共同符合相同架構的限制。

04　搜尋設定

固定 v0.2 單一 PE array 模板：每顆 16 PE、共享 1 MiB L2，獨立 IO。系統自動搜尋可用晶粒數量、合法 Mesh 排列、分割與跨層融合策略。

影響 CPU 側搜尋量與時間上限，不改變硬體速度或 PPA 限制。

Batch=1 時沒有其他可選 microbatch。系統不會改變使用者的工作負載。
