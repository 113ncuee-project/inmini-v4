# RL是否學到：獨立控制設計上的診斷

來源9ee，2026-11-04。這是已完成PPA資料的重新分析，沒有新增PPA或SGD。所有模型階段對同一組未參與該RL訓練的控制設計作預測；共享與RL已觀察過的物理設計依canonical identity排除。

種子37的整體排序變好，固定架構／分組內的細排序卻退步；種子7呈現整體泛化退步、細排序變好的相反情況。這支持「確實有學習，但泛化不穩定」的診斷。不能只報有利的相關係數，也不能把pair數當作獨立實驗或PPA次數。

這些控制設計形成固定診斷corpus，沒有完整實評原始每一步所有候選；挑選corpus內最佳預測不能當成一次真正的DSE勝利。V是成本輔助模型，future-Q的因果收益仍須由凍結策略、均勻策略和零折扣控制驗證。

進一步檢查舊版多步H分支：RNG47在55個真實轉移上的輸出標準差只有3.33e-9，但其當前Bellman bootstrap target標準差為3.90，第二層Tanh的64個單元全數飽和。RNG7也出現全數飽和；RNG37則仍有1.4975的H標準差，並非所有訓練都退化成常數。三個暖身checkpoint的H Adam step都已累積1992次，即使暖身只訓練V。成本頭有學習，不能據此宣稱多步分支總能區分動作。這是已存checkpoint的零PPA／零SGD診斷，target不是已知最佳回報。

新版原型因此固定已支付共享階段的成本先驗，以自己的新PPA擬合殘差，並修正continuation的Tanh飽和與共享暖身使未訓練Adam累積空更新的問題：V-only暖身、LayerNorm／SiLU、以log-cost單位計算TD loss，原始reward／Q／discount不變。訓練內LOO選擇殘差基底與正則化。9項針對測試已過；202項整套回歸、實際CLI／GUI／並行精確恢復及新DNN對照尚未全部完成，尚未證明搜尋更好。
